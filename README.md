# Hello, Tx.

个人博客，部署在 Netlify，域名 hellotx.duckdns.org。

## 自己写文章

1. 在 GitHub 网页上打开 `posts/` 目录，点 **Add file** → **Create new file**
2. 文件名填 `posts/你的标题.html`（英文小写，用 `-` 连接）
3. 把 `posts/welcome.html` 的内容复制过来，只改这几处：
   - `<title>` 里改成文章标题
   - `.article-meta` 里的日期和标签
   - `.article-body` 里的正文（`<p>` 一段，`<h2>` 小标题）
4. 点 **Commit changes** → 网站 1 分钟内自动更新

## 改完记得更新归档

`archive.html` 里加上新文章的链接（按标签、按时间两处）。
